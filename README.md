# figma-education-test

Figma 교육 자료와 실습 예제를 정리하기 위한 테스트 저장소입니다.

현재 저장소에는 README 외의 프로젝트 파일이 아직 추가되지 않았습니다. 이후 강의 자료, 실습 산출물, 예제 파일, 운영 문서가 추가되면 이 문서를 함께 갱신해 저장소의 최신 구조와 사용 방법을 안내합니다.

## 저장소 정보

- 저장소: `TangunsoftFigma/figma-education-test`
- 기본 브랜치: `main`

## 목적

이 저장소는 Figma 교육 과정에서 사용할 수 있는 자료를 실험하고 정리하기 위한 공간입니다.

주요 사용 목적은 다음과 같습니다.

- Figma 교육용 예제와 실습 자료 관리
- 디자인 시스템, 컴포넌트, 변수, 토큰 관련 학습 자료 정리
- 수업 중 사용하는 샘플 파일 또는 문서의 버전 관리
- 교육 콘텐츠 제작 과정에서 필요한 테스트 자료 보관
